# Gyro preview lifecycle consumer

Finite new sidecar. Eleven ordered lifecycle cases at 1280x720 and 1280x800 compile/mount the actual GyroSimulationWindow SFC, GameHaptics, model, renderer, range3d loader and focus helper. External bridge IPC/windowApi, navigator, clock and RAF are owned memory terminals. Optional range3d resource is 404 or a deferred loopback provider protocol; this does not prove actual 3D rendering.

The original haptics eight cases are not repeated. Two single-source semantic faults compile/start and must fail their exact UI/memory feedback assertion. Product failures remain FAIL. Source pins come from the full B43 root/manifest. Existing B43 diagram resolveUiToolContext and the original audited Node/UI tools are reused without adding a diagram spec. No shared registry or gate changes. Registration is supplied separately by adapter.mjs / descriptor JSON for parent integration.

Software evidence only: no real controller, SDK, OS input, App, Host, Steam, sleep or stress. A memory zero/reset request does not prove downstream physical neutrality.
