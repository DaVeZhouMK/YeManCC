# Library workspace datachain consumer

Independent finite global adapter. Parent integration imports `getAdapter(repoRoot)` from adapter.mjs and appends its single return value to the reviewed plan. No registry, runner, audit or product edit is included.

The original producer is pinned by SHA and copied byte for byte, with app.js and index.html, into each newly owned `<evidence>/<case>/sourceview/repo`. Its original `root/../../Build` guard resolves to `<evidence>/<case>/Build`. Positive app.js and HTML are byte identical to the supplied repository; each negative changes one exact app.js expression only. Producer bytes, case names/order, assertions and both 1000-combination loops remain unchanged. Fixture paths and URLs are literal memory data, never filesystem or network inputs.

Run with the reviewed Node executable: `node tools/ymcc_sim/global/library-workspace-datachain-consumer/run.mjs --repo <repoRoot> --evidence-dir <freshOutsideRepoPath>`. Optional `--current-root <primary>` compares the same three source inputs before/after. Mainline and a complete immutable snapshot are accepted; no snapshot version or D drive path is embedded in runtime logic. An existing output directory is rejected. Suggested and adapter timeout is 30000 ms; artifact input limit is 3072 and this adapter declares only the actual Node executable.

Only built-in Node VM is used. The preload observes exact original VM code without rewriting it, records UTF-16 source offsets/lines/code/SHA, original calls and actual assertion exceptions. Node's permission model restricts producer reads to its owned case and reviewed helper directory and restricts writes to that owned case; the observer further permits only the exact three inputs and original report output. The original producer is not patched. Actual stdout, stderr, original report and trace remain separate from tool-control receipts. Original negative allPassed=false is retained.

A negative counts only with all 40 original names in order, both original loop counts, all six VM evaluations completed, observed normalization/artwork calls, exact expected failed names and original ERR_ASSERTION exceptions. Missing source/output, syntax/VM errors, wrong fault, changed tool/input/config, stale report and partial execution are control failures. They never count as semantic detection.

Sources, external artifact (actual Node), reviewed helper identities and owned outputs are separate. Sourceview is deliberately finite, not a claim of a complete copied repository. A supplied snapshot manifest is checked for completion and membership of consumed inputs and its SHA is preserved before/after; the parent owns complete snapshot verification. The snapshot's unrelated external package binding is not claimed as used.

Maintenance: `node --test tools/ymcc_sim/global/library-workspace-datachain-consumer/contract.test.mjs` with `YMCC_WORKSPACE_TEST_REPO=<source>` and `YMCC_WORKSPACE_TEST_OUTPUT=<freshOutsideRepoPath>`. Tests retain their evidence and never touch real libraries or Steam. Do not infer browser rendering, native workspace80 operations, device/Steam behavior, installed acceptance, HC fixed24 reopening or whole-global acceptance.
