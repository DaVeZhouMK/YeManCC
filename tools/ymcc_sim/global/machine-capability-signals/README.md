# Machine model software capability consumers

This adapter reuses the existing `hc_remaining_model_capabilities_selftest.mjs` and its independent pinned historical HC oracle. It compiles the actual current native identity resolver, OEM catalog/query lambda, IMU matrix mapping, capture declarations, keyboard evaluator and in-memory power predicates. The production native source is not changed.

Two original configurations and all ten deliberately bad compiled variants must complete. Ten target model definitions,63 target aliases and80 old classes/181 old aliases retain the original checks. The OneX BUS hardware admission block remains a source comparison; no BUS reader, Windows hooks, physical input, Host or real sleep runs.

The wrapper records original raw source hashes, every external reference artifact and every generated result/binary/log in the same case. A line ending comparison normalizes only CRLF to LF; raw byte differences stay visible. An absent original baseline or pinned reference file is BLOCKED. A generated-only report, missing configuration/group/mutant or source drift cannot pass.

Use the existing global entry with test `controller.machine-model-capabilities`. This is software behavior evidence against the named historical oracle, not an all-device hardware claim or proof of current HC DLL independence.
