# Native / managed lifecycle pipe regression

This adapter runs the complete current native request, envelope, transport factory/IO/close, fast receipt scanner and DOM validation against the actual managed pipe loop, codec, parent lifetime and HostSession consumers. Only the existing SDK, PnP, fake clock and optional diagnostic ends are replaced. It never starts normal YMCC/InputHost Main or real input devices.

The original seven cases cover all three current personas, repeated RECREATE, quiesced-frame refusal/sequence continuity, one failed release barrier and retry, broken-pipe cleanup, and a foreign Host instance response. Nine additional cases hold an actual HostSession target while a distinct owned watched process exits normally, is forcibly terminated, or is terminated with the first output-stop attempt failing, for each of SteamDeck, DualSense Edge and Elite. The supervisor retains its server pipe until Host natural exit, so pipe close or a release command cannot substitute for parent-exit cleanup. State after the actual loop must already show cleanup, or retained objects/debt before the original final retry. There are16 cases per native configuration. Two private source mutations must fail the original sequence and identity assertions in both native builds after successful compilation.

The managed fixture is compiled separately so a run need only load its pinned output and .NET runtime. `managed-fixture.json` binds the explicit manifest; that manifest binds all current sources, generated snapshots and runtime files, and the child verifies them on both entry and exit. A stale prerequisite is blocked rather than rebuilt or silently reused.

To rebuild after a managed source change, run the existing `tools/input_lifecycle_managed_fixture.mjs --out <new evidence build directory>`, then update the reviewed manifest path/SHA in `managed-fixture.json`. Do not edit the manifest to certify different source bytes. Native source changes are compiled for each run.

Run through the existing public simulator entry with test `controller.lifecycle-native-managed-pipe`. Evidence and child pipes are private to the case. Compiled fixture identity, software lifecycle proof, actual driver/SDK teardown and physical input return are distinct; this adapter only accepts the first two within its documented ends.
