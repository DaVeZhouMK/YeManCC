# Battery native → existing Host memory consumer

This leaf preserves the current whole `native/battery_charge_client.h` and byte-identical `tools/battery_charge_transport_selftest.cpp`, then executes their real requests through the current Host request statements and the existing battery-signals `Rig/Controller/MemoryStore/Fake`.

Run only through the parent-owned global registration after READY. An explicit private candidate is available with `node tools/ymcc_sim/global/battery-native-host-roundtrip-consumer/run.mjs --evidence-dir <fresh external absolute directory> --prototype`; its outer result deliberately remains FAIL while `prototypeWorkerPassed` records the private worker. It never registers itself.

The 14 fixed normal/error scenarios and one compiled `matchingHost` guard-removal fault are in `tools/fixtures/battery_native_host_roundtrip/cases.json`. The original assertion must report `old helper not diagnosed before set`, with natural code 23. Compile errors, timeout, early exit, missing receipts or an unrelated exception cannot satisfy this fault.

The current two csproj source/resource/reference graphs are read at run time and compiled with direct Roslyn. Current consumer code and Host request statements are captured from the repository every run; no historical generated source or D workspace is imported. Direct compilation is an evidence recipe, not the normal full project/package build. Synthetic implicit usings and the test-only entrypoint are recorded. Runtime/tool closure is bound in `toolchain-inputs.json`; missing actual inputs reject the run instead of truncating the list. DLL references, complete selected BCL runtimes, compiler dependencies/resources, native includes and searched libraries are retained.

A short, exactly owned scratch directory is allocated using the existing scratch helper. The exact original Job class is extracted from `host-process.ps1`; its small C# wrapper gates Node before Job assignment. All descendants share that Job. Actual native/managed exits and requests/responses are recorded. Raw scratch bytes are archived without rewriting their paths; mapping connects original paths to evidence copies. Successful owned scratch cleanup happens only after archives are verified.

Boundaries: Win32 pipe/process identity/clock APIs and Host duplex stream are explicit memory ports. Standard CRT, own D/C evidence IO and shell command-line argument parsing use normal OS services. Actual owned stdin/stdout carries data, but this does not accept real namedpipe ACL/parent authentication/kernel cancellation, production Host Main/Serve/global ownership, real old Host binaries, WMI/EC/HID/driver/device behavior, physical readback, installation or whole-product performance. Literal old selftest output containing “real helper” remains unchanged and is not a claim about a real Host process. `--parent` and `--expect-early-exit` branches are compiled but not executed.

No product patch is introduced when original behavior is correct. Unknown commit replies remain unconfirmed and are followed by an explicit GET, without replaying SET. The software release scenario must restore the owned original fake device state.
