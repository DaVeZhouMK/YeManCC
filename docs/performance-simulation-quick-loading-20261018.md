# 快速模拟加载状态 · 2026-10-18

快速模拟执行中使用转圈提示，并保留当前场景、已模拟秒数及百分比；旧横向进度条移除。环形提示只在running状态播放。

五场景运行完成后，机型/分辨率/瓦数说明、转圈和状态文字所在的整个plan-loading容器隐藏，宽高均为0。不是仅隐藏环形图后保留空行；A/B交换重新绘制结果时也不能恢复加载占位。

关闭弹窗或按B取消会清理状态并停止动画。异常时只显示失败文本，不能继续转圈；参数变化导致结果过期同样退出加载态。计时、有限任务及统计算法未修改。

浏览器实际运行五个场景共63分镜、252秒模拟，产出全部场景加五个分场景的12行A/B结果。核验1280×720和1280×800完成后加载容器的宽高、动画数均为0，同时检查取消、重开和异常退出。统一监控18组布局回归继续通过。

本次通过静态覆盖导出主线Test目录，复用已校验的原生及PowerControl配套文件，导出资产与源码哈希一致。启动入口为Test/Start-Mainline-Test.cmd。
