# 常态监控解析：移除重复读数复制

现有统一 HWiNFO 消费链在缓存未命中时先将读数表复制到 `parseScratch`，再将同一份读数复制到复用缓存。本轮让支持缓存的输入直接从缓存拥有的字节副本解析，免去 `parseScratch` 的重复复制。

## 保留的约束

- 所有数据仍走 YMCC 唯一采集层，不增加线程、定时器、硬件接口或快照消费者。
- 不改生产者时间、显示频率、Presented FPS 主源、RTSS 救援或 HWiNFO 配置。
- 缓存继续限制为最多 1 MiB（含传感器身份表），支持周期仍为 1500..60000 ms；1000 ms、未知周期、超大表、没有缓存 owner 时继续使用原解析路径。
- stage 分配失败不影响本轮真实采集，回退到原 scratch；header/周期/身份复核、最多三次不稳定读取重试仍保留。
- owned rows 仅在本次解析期间借用，不交给 UI 或消费者；代际、源映射变化、闲置和失败会使其失效。
