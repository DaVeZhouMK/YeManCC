# YMCC 性能调度与顶部专属配置：导航、数据与反推检查

日期：2026-10-18。检查对象为公用性能调度、顶部专属配置及自定义手柄 TDP 快捷键。

## 已修复

1. 顶部菜单沿用旧 AC/DC 行标记，方向向下会越过整个新性能面板，直接落到专属手柄。现在统一使用新面板行列导航；专属入口向下进入首行，末行向下到手柄/陀螺仪，向上沿原列返回。无大小核/SMT 的控件不参与焦点。
2. 顶部输入编辑原来把整份旧配置覆盖回文件。已用旧 UI 函数与真实快捷键事务交错复现：快捷键 19W→20W 后，选择手柄写回19W。现在只合并手柄/陀螺仪/启用字段，保留20W及CPU、另一供电侧、RTSS和扩展字段。启用/失败回滚也仅修改启用字段，并核验原启用状态。
3. 性能滑块按 B 或上下退出编辑时可能残留未保存的显示值。现在先取消当前编辑，重新读取当前所属配置。若快捷键此时已更新TDP，回读最新值，不恢复旧快照。下拉框 B 优先关闭下拉框。
4. 自定义快捷键配置5W/10W步长，前端却只传正负1。现在完整传递1–20W整数步长，统一限制在机型硬件边界和当前滑块上限内；非法步长拒绝。既有快捷键冷却及写入队列保持原策略。

## 数据反推

自定义规则 power.tdpAdjust / 默认 Start+方向 → 原生 gamepad.tdp-delta 事件 → App.vue applyGamepadTdp → adjustContinuousPerformanceTdp → effective所属配置 → updateContinuousPerformanceControls → 当前AC/DC连续参数 → 同一性能应用与浮动入口。

- 专属启用：快捷键和顶部面板接该EXE的专属数据；关闭则快捷键回到全局数据。
- 公用性能页固定接 global；顶部面板固定接 dedicated；两者复用 ContinuousPerformancePanel。
- 手动与自动共用该侧TDP字段，手柄不再另写一份TDP；编辑非当前供电侧只保存，实际供电侧不改变。
- CPU、频率、积极性、睿频、大小核与SMT沿连续配置读取；旧公用/专属数据只用于一次性迁移，已有连续参数优先。
- 帧率由原有独立帧率模块持有，更新性能/输入不能覆盖RTSS或其它游戏条目。
- 所有专属字段修改进入既有文件队列；校验设置代次、EXE、PID、进程创建标识。过期身份、切供电和旧revision均拒绝。
- 浮动仍为原有单一控制器；未新增定时调度。输入修改/取消编辑不启动另一套TDP控制。
