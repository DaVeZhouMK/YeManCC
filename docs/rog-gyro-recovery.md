# 陀螺仪百式恢复范围

2026-11-03 用户确认：百式先作为 ROG 专用恢复，其他机型待玩家反馈与日志后逐款适配。用户反馈 GPD 当前正常；该反馈不代表已逐款完成物理验收。

原生范围复用 `machineIsRogAllyFamily()`：RC73XA、RC73YA、RC71L、RC72LA。GPD 等非 ROG 机型不启动百式观察或恢复任务，不重建其 Windows 传感器，不进行设备级禁用/启用；原有传感器输入与通用明细日志继续使用。该限制只约束百式，不能用来关闭其他来源本来的传感器处理。

ROG 开启有效陀螺仪后，先观察当前数据，不要求先切换预设或晃动。数据健康则完成有限观察并停止任务。低数据回到新的动作 episode 门，沿用一次恢复、暖机、实际样本验证和关闭取消；不因静止自动反复重置。WinRT 恢复只在对应源通道执行，设备级 PnP 进一步限定为 ROG 的 ACPI BOSC0200。SensorAPI 数据可观察，不能借道重建另一个 WinRT 源。

计数使用当前绑定内递增的有效时间戳，重复、倒序、零时间戳及非数值样本不能伪造健康；正常高频与延迟泵拍不受旧 120 样本/秒上限误伤。BOSC0200 保留已取证的约 25Hz 健康下限，受硬件报告间隔约束；不能把申请 10ms 写成实际已达到 100Hz。其他 ROG 来源参考自身报告间隔，频率与最终游戏输出分别记录。

2026-11-03 21:41:18 导出的 ROG Xbox Ally X 日志中，21:30:18 有效电源已开，但触发方式仍为 off、触发键为空。21:40:02 选赛车后才变为 on。因此另修通用显式启用事务：开启时带上所选预设的完整触发/输出参数，保留合法的独立预设与旧配置，不在页面载入时改写启动意图。此参数接线修复适用于全部输入入口，不属于百式品牌恢复。

同一日志的百式在 21:36:55 按旧标准完成：连续三段分别约 40.14、34、33Hz。该结论只证明当时陀螺仪供数达到旧门槛，不等于触发键成立、输出处理已就绪、Host 接收或游戏已经消费。详细日志现分别记录实际按键、触发准入、处理器就绪、报告间隔以及两种传感器的序列/年龄。

下一机型的适配须以玩家反馈中的机型、数据源、实际频率与故障前后变化为依据；不得直接把 ROG 的 PnP 动作或频率下限推广。离线原生消费者与浏览器回放证明软件接线及边界，不替代该机型的传感器、手柄或游戏实测。
