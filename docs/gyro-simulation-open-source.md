# 陀螺仪模拟小游戏来源与边界

参考仓库：https://github.com/pakastin/car
固定提交：`d81c77289ba45830b7f771755295fbb949dfc9e1`
源文件：`car.js`；许可：MIT，完整副本在 `src/gyroSimulation/pakastin-car-LICENSE.txt`，核心模块保留许可注释。

采用加速度→速度→位移、角速度阻尼的简单顶视车辆思路；按 delta time 处理，加入本地赛道、离路阻力、制动优先与跟随镜头。没有引入原项目的联网服务、socket、射击功能或用户身份逻辑。原示例没有此次所需的赛道 AI；本地三个对手单独实现前视循迹、弯道减速、临近玩家换道，现已统一接入本地刚体碰撞。

靶场、投影绘制、枪口后坐力、回落、命中倒靶、移动靶与记分为本地代码；没有使用《战地》或 COD 的贴图/模型。原有陀螺仪设置和原生映射保持唯一所有者，小游戏只读当前获准的 `motionContribution` 与已有 `gamepad.state` 双摇杆/扳机状态。H5 才可读浏览器标准手柄快照。试玩模式消费本地导航/扳机命令，B 返回调节后恢复页面控制。

## 轻量 3D 武器（2026-10-18）

保留 YMCC 原有 Canvas 靶场，仅增加墙面两侧柔和光感。武器单独以 WebGL 深度测试绘制，开镜继续使用同一靶场的独立 2× 渲染；原生陀螺仪、命中判定和设置仍由原模块持有。

参考入口：https://github.com/SouthHorizons76/EFTForge 。该仓库 README 的 Kitbash 章节说明 3D 引擎为单独的私有项目；没有复制该引擎实现，也没有复制其 AGPL 应用模块。选用公开查看器提供的一套 M4A1、Geissele MK16、Vudu 及连接部件，共 14 个 GLB，原地址和处理后文件信息见 `public/gyro-simulation/models/m4-vudu.json`。这些是游戏美术资源，不声称适用 EFTForge 的开源代码许可。当前用于用户指定的本地预览。

贴图统一为 256px WebP，保留原模型的 meshopt 几何压缩；不加载全量机型/武器目录、环境资源、联网大厅或 Kitbash 查看器。Three.js 固定 0.186.1，MIT 许可完整副本位于 `public/gyro-simulation/three-LICENSE.txt`；GLTFLoader、meshopt 解码器同包引用。完整新增静态文件约 2.1 MB，构建工具设 2.5 MB 上限。

独立源码：`tools/gyro-runtime/range3d.js`；生成命令：`node tools/build-gyro-3d.mjs <three-0.186.1-npm-package-directory>`。生成运行时仅在打开模拟窗口时动态加载，退出时释放 WebGL 上下文、几何与材质；加载失败显示简化预览状态。

射击以固定种子的散布锥改变实际弹道，ADS 缩小散布，水平后坐力参与下一发弹道并逐渐回正。赛车以统一的 3.2 绘图单位/米推进玩家与 AI，起步 90 km/h，实际位移与加速度均增加；镜头仍仅平滑平移，保持北向，不跟随车身旋转。

## 枪口与赛车细化（2026-10-18）

枪口不再用包围盒估算，直接使用原 M4 制退器模型的 `muzzleflash_000` 发射挂点。火光贴图由公开的 `muzzle-smoke.json` 中引用的 2×2 原图集缩为 256px WebP，只增加约 28 KB，出处与原始 SHA-256 见 `public/gyro-simulation/muzzle-flash-source.json`。外侧火光参与武器深度测试；镜内为独立 2× 投影，仅在瞄准镜裁切区绘制，降低亮度。前握把使用同一模型库的 DD M-LOK enhanced vertical foregrip，接入 MK16 的 `mod_foregrip` 挂点，沿护木前段安装。持枪位置、原有视角不变。30 发弹匣使用已加载的原弹匣模型；空仓后绕枪管轴线顺时针侧转约 41°，沿弹匣插槽拔出、插回后再回正，换弹不附加前后移动或抬枪平移。

赛车按用户最新反馈保留原有车身和 Canvas 画风，仅增加阶梯观众席。未将研究用 Kenney 素材加入发布文件。道路半宽统一为 78 绘图单位，渲染与出路判定使用相同常量；起步 90 km/h，提高油门加速度。草地不再瞬间钳制为 14 m/s，而是降低加速度并增加较缓的阻力。物理以不超过 1/120 秒的子步更新，镜头保持北向平滑平移。

腰射状态保留真实后镜片几何，使用约 90% 不透明的深色玻璃与轻微反光；进入 ADS 时淡出该遮罩，不遮挡 2× 镜内视野。标靶外框与内框分别固定为 0.7 CSS 像素，避免继承场景栏杆/轨道的线宽。

## 四驱越野赛车（2026-10-18）

赛车逻辑集中于 `src/gyroSimulation/race.ts`，由原 `model.ts` 保持导出入口；只有这一套赛车状态与物理推进。沿用现有 Canvas 场景和稳定北向镜头，车身改为四驱越野车，加入宽胎、车架、备胎、车顶防滚架，赛道改为砂石、草地、泥地和三个有实际高度的土坡。道路半宽由 78 扩为 93.6，正好加宽 20%，出路判定与绘制继续共用常量。没有新增贴图、第三方物理引擎或联网资源。

玩家与 AI 使用同一套轴向轮胎力、前后轴驱动力分配、有限抓地圆和纵向载荷转移，油门、制动、转向共同受轮胎抓地上限约束；空中不提供轮胎驱动或转向力。固定子步最长 1/240 秒。车辆与场内石块、轮胎堆、木桩使用有向包围盒分离轴检测，接触冲量包含质量、角惯量、恢复系数和切向摩擦，先分离穿透再更新双方线速度、角速度；不再以重叠时统一减速代替碰撞。

土坡提供连续高度和表面梯度；冲出坡顶后保留垂直速度，按 9.81 m/s² 重力抛物线落地，用阻尼弹簧呈现悬挂压缩及回弹。阴影保留在地面，车身按高度抬起，镜头不随车身翻转。刹车或侧滑按后轮实际位置生成两条连续胎痕，寿命从 3 秒延长为 9 秒，设 900 段上限；腾空不留胎痕，落地与碰撞产生有限寿命尘土。

这是本地轻量驾驶模拟，碰撞与腾空会实际改变状态，并非完整的车辆工程或实车标定模型。附加测试 `tools/gyro_race_physics_selftest.ts` 检查动量与能量、障碍反弹、擦碰角速度、高速防穿透、空中失去轮胎驱动力、落地、双胎痕与寿命，以及 30/60/120Hz 一致性。H5 使用真实组件与正式手柄引擎回放，物理手柄验收需另记。


## 输入与反馈

模拟窗口仅包含室内 FPS 靶场和四驱赛车。Start 从调节区开始测试，B 返回调节，再次 B 关闭；A 保留选择场景和编辑参数的行为。开着下拉或确认框时 Start 不穿透。测试中的方向输入由游戏消费，不会改动右侧菜单。

两种游戏共用短脉冲震动，事件为射击、命中、换弹、碰撞、落地和轮胎打滑。退出、失焦、断开或切换场景会停止反馈；无震动设备保持可玩，不伪报成功。软件回放不替代实体手柄验收。

赛车 LT 先刹车，停稳后继续按住进入倒车；RT 先结束倒行再前进，双扳机保留制动优先。AI 沿用倒车转向、前进恢复的脱困过程。
