# 原生监控汇总包字段节点复用 — 2026-10-17

本轮已合入主线 native/main.cpp 的 nativeMonitorTopPayloadText；没有部署或重启本机程序。没有改变 HWiNFO 配置、采样周期、唯一数据层、时间戳、数据有效期、RTSS Global 范围、FPS 优先级或显示规则。

## 改动与边界

原实现每次为同一套最终 JSON 字段新建有序 map 节点。现在为该唯一采集线程保留一个 thread_local 汇总对象；每次仍重写全部标量值，不用数值相等来跳过赋值，因此整数/浮点类型及负零序列化行为保持原样。核心图块和独立 CPU 有效性证明是可选字段，无对应输入时明确删除，防止上一包的信息进入下一包。

没有加入按时间/设备身份扩大的缓存表，只有各调用线程各自最后一个汇总对象。生产路径仍由唯一 nativeMonitorLoop 使用；工作线程退出时释放。核心数组原有有界来源和明确所有权移交保留。数据输出仍返回独立字符串，调用方不能修改内部对象。

通过独占短时写句柄精确替换当前函数，保留当时 main.cpp 其他字节和其他任务修改，没有回退整个源码文件。合入前的完整函数原字节逻辑保存在 tools/fixtures/monitor_top_node_reuse_before_20261017.inc。
