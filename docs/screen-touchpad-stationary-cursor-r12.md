## 显示规则

`native/screen_touchpad_cursor.h`增加UI线程自有的一个坐标锚点和布尔授权状态：

1. hidden新SD手势首个成功系统坐标只锚定。
2. SUPPRESSED样本的实际XY不同于上一有效锚点后，允许补画；不推算位置。
3. 授权跨上传、准备后查询、定位等瞬时失败保留，让静止重试仍可恢复。
4. 任何已查询的非SUPPRESSED状态清除旧授权，包括visibility路径中的SHOWING+NULL；新手势/模式切换/Stop清理锚点。
5. 现有visible补画继续按原预算更新；系统有效SHOWING或flags0仍按原规则交接/隐藏。
6. 静止UP即使保留hidden观察所有权，也不额外显示旧箭头；真正的后续受抑制运动仍可显示。

开销是既有成功采样中的整数比较和固定大小状态写入。24ms观察预算、BUS前后提交顺序、合并规则不变；静止阶段提前返回还能避免光标图像准备、上传和显示调用。没有测得进程CPU百分比，不给出推算降幅。
