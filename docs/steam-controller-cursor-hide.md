# 手柄模式隐藏鼠标

2026-11-11：位于 Steam → 联动与状态 → 大屏快捷入口，在 Steam 插件商店下方，默认开启。设置键为 `ui.steamControllerCursorHide`；旧配置缺字段视为开启，保存的 false 保留。功能独立于插件商店开关，不启停 Steam、游戏或输入后端。

只使用 YMCC 已有的游戏身份发布，前台窗口必须属于该游戏的同一 PID 和出生时间，并由现有 Steam 本地追踪消费者确认关联。仅连接手柄、空闲报文、摇杆死区内漂移均不算操作；需要现有物理采样观察到有效操作。鼠标移动、按键和滚轮始终正常传递，没有输入注入、鼠标锁定或焦点切换。

首次观察到合格前台游戏后，前 60 秒每 5 秒检查一次，包含第 60 秒，共 12 次；以后间隔 30 秒。至少 3 秒没有鼠标操作才允许隐藏。没有实际手柄操作时不读取 Steam 日志；Steam 关联确认后复用进程寿命内的结果，持续检查不再读取日志、扫描进程、访问注册表或调用 Steam RPC。有关联查询但 60 秒仍无法确认的目标退出候选轮次，不进入持续日志轮询。

鼠标真实坐标改变、点击或滚轮立即撤销本功能隐藏，并停止该 PID 的轮次。坐标未变的 WM_MOUSEMOVE 不视为移动。切出游戏或换到其他前台窗口时也撤销隐藏并终止该轮；切回、重开页面、同值保存和关闭再开启此选项均不会退还该 PID 的已终止预算。进程退出通过其 HANDLE 的一次性系统等待通知结束，按 PID 加出生时间区分重用；记录属于当前 YMCC 原生会话。

睡眠仍只消费原共享电源 owner。消息不携带历史状态供本功能重放，处理时读取当前一致快照；游戏上下文、到期检查和首次鼠标终止也轻量读取同一缓存，防止投影消息迟到期间继续隐藏。只接纳递增 suspendSerial；倒退水印、重复 Ready、前端恢复和输入恢复尾部不会退还预算。新水印先清除上一睡眠轮的停止记录，60 秒计时在 Ready 才开始；同一新水印内已经发生的鼠标操作或失焦记录保留，迟到 Ready 不会再次抹掉。非 Ready 立即还原光标并停止检查；Resuming 保留原鼠标观察来接住鼠标操作，Suspended 撤下本功能租约。没有新增电源订阅或睡眠轮询。

鼠标事件优先复用已安装的 OEM 观察器；没有 OEM 时，复用输入诊断模块的鼠标 hook，并单独持有鼠标观察租约，不因该功能开启键盘诊断或记录器。两条已有 hook 同时存在时只由 OEM 路径向本功能提供一次事件。前台变化沿用原 mousePolicy 的 WinEvent；只有当前有效轮次拥有一个 5/30 秒计时器。停止后撤下本功能租约和计时器，保留其他模块原有观察。

只对可识别的 Windows 标准系统光标做临时透明替换。自绘指针、私有游戏光标以及其他进程窗口上的指针不在隐藏范围内；游戏自身已隐藏时不强制显示。替换前必须保存原光标副本；撤销先加载当前系统方案，系统拒绝时用副本还原，不写系统光标配置或注册表。还原仍失败就停止后续隐藏并保留恢复责任，鼠标事件可再次恢复，不能重开已终止的游戏预算。恢复进程初始化及写光标前后均检查前台，迟到结果不能继续影响桌面。首次建立恢复进程不再同步等待就绪，未就绪时沿原 5/30 秒检查再试，没有附加计时器。

同映像独立恢复进程在隐藏前就绪并保存自己的原光标副本，平时仅等待父进程/退出事件。YMCC 主进程退出或崩溃后立即尝试还原；如果系统方案及副本还原都失败，恢复进程继续存活，仅此时临时安装鼠标观察，移动、点击、滚轮事件放行后由消息循环再次还原，成功后撤下观察并退出。正常隐藏期间没有第二套鼠标观察，没有后台重试轮询、窗口前台、设备或电源订阅；不允许安全脱离父 Job 时不隐藏。这一兜底以独立恢复进程仍存活及 Windows 允许恢复为边界，不能承诺恢复进程也被一并强杀、或所有系统恢复调用永久失败时仍自动恢复。

首轮以私有固定来源完成实际产品消费者的 32 项定向断言，包括 5/60/30 秒、鼠标终止、失焦不退还、PID 退出、睡眠重置及重复 Ready、未知关联、坐标重复、正常退出。1280×720/800 的真实 SteamView 和正式手柄 engine 已验证默认状态、A 开关、上下往返、左右边界、B 返回和可见性；缺省/ON/OFF 三组实际设置消费者及原 settings-baseline-contract 通过。旧固定来源的 GameBar 类型失败和所有准备/收尾失败前向保留，没有改写成通过。

本次健壮性续作复用原消费者，共 72 条断言通过（55 条原消费者及新增边界、17 条恢复进程/事件边界），新固定来源 MSVC 主程序语法检查通过。旧源码先实际复现 9 组失败，修正覆盖：唤醒通知迟到前已用鼠标、Resuming 中用鼠标、旧鼠标记录随新轮重置、pending/UNKNOWN/倒退快照、重复与倒序消息、旧手柄票据、系统方案恢复失败、所有恢复写暂时失败、原副本不可用、建立恢复进程或写光标途中失焦。实际受控父进程已结束后，独立恢复进程在显示终端替身中经历首次全部恢复失败，再由模拟鼠标事件触发成功恢复；事件始终放行，恢复进程自然退出。显示与输入系统调用隔离，没有操作真实用户鼠标或发出输入；真实进程、HANDLE、继承事件和退出等待实际执行，最终 Job 实际归零且无强制回收。没有重复 UI/设置检查；它们未改，引用首轮原件。私有快照遗漏既有 ADLX 头文件导致的编译失败、旧收尾读取不到 guard stdout 的失败及中间候选失败均保留。

低 CPU 检查：相同 PID、窗口与观察来源的 1,000 次重复身份通知没有重设计时器；新增 10,000 次重复共享电源通知也没有重设计时器或重读 Steam。确认后的模拟一小时只有 120 次检查，额外 Steam 日志读取和重复光标替换均为 0；终止后实际检测次数为 0。恢复进程正常路径额外鼠标 hook 为 0，故障路径仅临时建 1 个，接住 1 次模拟鼠标事件后归还；没有新 XInput 读取器、持续状态扫描或恢复轮询。未就绪恢复进程的主线程检查样本约 0.25 毫秒，原来的最多 1500 毫秒就绪等待已移除。首轮本机 20,000 次只读 Win32 查询平均约 7.03 微秒 CPU 时间及 wait-only 恢复进程 1 秒内 0 毫秒 CPU 的局部微测原件保留，它们未重跑，也不代表新安装版总 CPU。真实游戏兼容性仍需安装版观察；耗时探针仅在 Evidence 内，没有加入产品或自启。
