# 默认一体控制台与赛博朋克主题预览

默认性能调度与顶部专属内页采用一体控制台布局。模式与供电在同一行，模拟入口移至标题行，手柄坐标随视觉行列更新。标题20px、正文14px、摘要主值16px；保留既有全局壳体缩放。

当前参数概览固定三等分：浮动TDP区间显示调度下限至当前预算（例如38–55W）、CPU频率显示原频率范围、CPU积极性单独一格。无浮动时区间两端相同；手动模式显示当前固定TDP。专属内页沿用此前决定，不显示概览栏。

保存提示预留空间，设置保存前后不推动布局。无混合核设备压缩不可用调度区，超线程仍可独立操作。模拟测试编辑器沿用其原有密度与行列，通过同一个组件接入现有数据。

性能组件的script setup区与修改前逐字一致，修改限定模板/CSS及预览测试入口。未增加配置副本或另一套浮动调度。

赛博朋克主题只在H5中提供黑黄警戒、霓虹夜城、冰蓝终端三个候选，正式默认布局已采用；候选主题尚未替换正式主题。H5直接编译生产ContinuousPerformancePanel和GameCustomProfilePanel，设备/保存边界为隔离内存，监控为示例。

验证：64组H5布局与4套交互（默认+3主题），720P/800P、自动/手动、AC/DC、公用/专属均通过。摘要列宽差小于1px，实际字体14px/摘要16px，值与当前bank同步；公用/专属隔离。原生输入分发/生产导航16组、面板8组布局、模拟分屏4组，以及24项配置状态检查通过。Vite重新编译及Vue类型检查通过。实机控制器手感仍需用户确认。
