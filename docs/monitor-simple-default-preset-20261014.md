## 默认与数据项

“简约”内置 21 个独立开关，不保存截图示例数字：

- FPS：FPS、帧率上限、1% Low、帧时间曲线。
- CPU：TDP 上限、功耗、温度、频率、核心负载图块。
- GPU：利用率数字和图形、功耗、频率。
- 内存：内存与显存的使用率数字及图形。
- 电池：剩余电量数字与图块、功率、时长。

默认外观为轻量胶囊；Tasha Seversky；FPS 突出显示；无数据自动隐藏。缩放 100%，文字对比度 100%，背景不透明度 80%，图片透明度 75%（图像不透明度 25%）。位置沿用左上角。

“精简 / 标准 / 详细”保留。“简约”有独立数据开关记忆；切换预设不覆盖其他预设；重置仅恢复当前预设的数据项，外观设置继续独立记忆。既有用户设置不因通用模型默认更新而自动重置。
