# YeManCC v0.0.41

本版在 v0.0.40 的基础上修复升级安装与恢复问题。Xbox 全屏及游戏内呼出功能保留。

## 升级安装

- 安装先尝试正常关闭已识别的 YMCC 相关进程和受支持的外部工具；超时后，对身份仍匹配的进程进行有时限的强制关闭。无法关闭的进程会留下日志，不会跳过后续文件的更新尝试。
- 不再要求所有旧文件都能读取或备份才开始更新。新版托管文件优先覆盖旧文件；无法更新的可选组件会记录为未完成项。关键文件若最终无法替换或验证，仍会尝试处理其余文件，但不会把混合版本标记为安装成功；安装器会尝试回滚并给出重试状态。
- Steam 游戏库的升级健康检查使用临时配置，避免损坏或不可用的旧配置阻断验证，并兼容旧安装器所需的健康标记。
- 日志导出增加更新阶段、安装失败和回滚状态，便于区分下载、关闭进程、文件替换与启动验证故障。

## 从旧版升级

打开 **设置 → 更新 → 版本和更新**，下载后选择 **安装并重启**。如果 `v0.0.39` 或其他旧版的内置安装器仍然失败，先导出日志，再关闭旧版，用本页的 `YeManCC.zip` 解压到一个新的目录启动；不要手动把损坏的配置复制进去。当前运行的安装代码来自发起升级的旧版，不能保证本版修复都能作用于这次安装。
