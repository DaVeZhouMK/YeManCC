## YeManCC v0.0.44

- **升级与安装**：普通配置或可选文件写入失败会记录并继续尝试其余文件；核心程序写入失败不会当作成功启动。加强了安装和失败回退的日志。
- **风扇与设备**：更新风扇唤醒和控制权交接，加入 GPD WIN Max 3 的风扇与专用按键识别。部分设备的物理行为仍待真机验证。
- **Steam 与手柄**：调整 Steam 自定义库快捷方式的启动识别，更新手柄唤醒、输入服务退出和触控板链路。

`YeManCC.zip` 是完整程序包；`YeManCC-source-v0.0.44.zip` 是对应源码。下载后可用 `SHA256SUMS.txt` 校验。
