# YeManCC v0.0.33

## 更新内容

- **控制器与陀螺仪**：完善映射、输入状态、配置管理和快捷操作入口；虚拟输出与陀螺仪启动意图分别保存。
- **游戏专属策略**：临时接管输入配置，不回写污染全局预设；游戏目标切换加入有界确认。
- **启动展示**：完善首屏与输入启动请求的就绪门禁，失败状态明确显示。
- **监控与 RTSS**：整理监控快照、新鲜度与日志频率；更新 OSD 热切换及配套桥接插件/helper。
- **睡眠与恢复**：加强用户唤醒授权、进程身份、取消条件和有界恢复重试。
- **风扇控制**：正式运行路径统一为 `PowerControl/fan-host-v2`；风扇与 HC 运行时按清单校验身份。
- **Steam 游戏库**：更新自定义游戏库与界面，增加源码指纹及导出身份门禁。
- **界面与诊断**：整理快捷应用、手柄导航和日志导出；详细日志默认关闭。
- **自动更新**：补强大包断点续传、重启恢复、缓存身份绑定和完整缓存离线复用；不支持续传或校验失败时安全重下。
- **源码构建**：InputHost 使用仓库内的锁定依赖，移除开发机 Archives 路径要求。

## 安装与升级

- 正式附件唯一名为 **`YeManCC.zip`**，同时用于完整安装与自动升级，不使用 `YeManCC-Complete.zip`。
- 公开 028 客户端沿用该包名升级。033 更新失败按事务回滚；后续同协议升级按新 ZIP 清单校验，不锁死旧载荷哈希。
- 保持 ZIP 目录结构。`CustomSteamLibrary` 位于 `YeManCC/CustomSteamLibrary`；风扇 Host 位于同级 `PowerControl/fan-host-v2`。
- 旧 `fan-host` 仅保留兼容，不作为新版本正式运行路径。用户配置、数据与未知文件按更新清单保留，更新前建议备份。

## 兼容性与边界

硬件能力以机型、已安装的配套组件与能力门禁为准；不声明所有设备均已验收。离线与隔离测试不代替实机冷启动、睡眠/唤醒、真实游戏 OSD 或全部 OEM 风扇测试。

直接从正式 V2 目录调用随包手工 `run-emergency-fan-restore.ps1` 的入口尚未验收；不要把它作为已确认的应急操作。正式 native 恢复链与这个手工入口分开验证。
