## YeManCC v0.0.42

### Xbox 全屏与游戏内呼出

- 修正窗口最小化后从浮层呼出的恢复顺序，保留最大化状态，避免 WebView 已切换到浮层后又被主窗口的隐藏状态关闭。
- 移除呼出主路径中的同步游戏识别；在 WebView 恢复过程中，对仍按住的 `LB + RB` 呼出请求最多补接一次。原有快捷键、监控与触控板的独立行为保持不变。

### GPD 风扇控制

- 更新 Win4 6800U 的 HC 风扇运行时及 Fan Host，修正冷启动风扇端口配对，并保留打开失败的诊断结果。
- 加固 Win5 从睡眠或休眠唤醒后的风扇接续：临时读不到状态时允许一次恢复读取，新的睡眠、手动关闭或用户的新设置不会被旧请求覆盖。

### 下载

- `YeManCC.zip` 是完整程序包；`YeManCC-source-v0.0.42.zip` 是对应源码。
- 使用 `SHA256SUMS.txt` 核对下载。请以完整程序包为准，不单独替换 Fan Host 或 HC 的 DLL。
