# YeManCC v0.0.40

## 亮点：Xbox 全屏支持，全屏游戏内呼出 YMCC

- **支持 Windows 的 Xbox 全屏体验。** 可在开机模式中选择「Xbox 全屏模式」，也可选择「Xbox 全屏模式 + Steam 大屏」。
- **全屏游戏内可呼出 YMCC。** 在支持的全屏游戏中，使用原有呼出键打开控制台，查看监控、调整性能或常用设置，不必先退出游戏。实际表现取决于游戏的全屏模式、设备和驱动，不保证所有独占全屏游戏。

## 升级与配置自愈

- **旧配置冲突时优先保证新版能启动。** 首次启动会检查主配置和备份；兼容配置尽量保留，坏 JSON、不支持的配置版本或无法继续读取的超限数据可回退到新版安全默认值。旧配置备份失败本身不会阻止恢复。
- **扩大可保留的旧配置范围。** 合法的深层扩展和无关的旧 `schema` 字段不再被误判。恢复到默认值时，不会从损坏的配置重新启用自动硬件操作或开机接管。升级后建议检查常用设置。
- **旧安装失败不再卡住下一版。** 在没有活动安装或受保护修复的情况下，后台仍会检查新版本；发现新的有效包后可以切换下载目标。同一个失败的包仍由用户手动重试，不会自动反复安装。
- **后台只下载，不自动安装。** 已校验的同一个包不会重复下载；检测到游戏运行时暂停后台下载，退出游戏后按条件续传。待安装包仍有效时，监控提醒每次 Windows 开机最多显示一次；安装需在更新页确认。

## 操作与设备

- **新增自定义触控。** 可添加自定义触摸按键，切换 SD、PS、Xbox 触摸手柄模板，并调整位置、按键和摇杆大小。屏幕触控板遇到短暂窗口错误时，重新选择当前模式可触发复查并清除已恢复的错误。
- **游戏专属配置可自动加入或手动添加。** 专属配置只记录性能和锁帧设置；手柄输入由全局设置和开机模式管理。外接手柄优先也由控制器页统一设置，不再随开机模式切换。
- **Steam 与设备组件更新。** 改进部分游戏的 Steam 三点菜单呼出位置，完善开机模式状态提示，并更新虚拟手柄、风扇、灯光和 Decky 侧边栏相关组件。具体硬件能力以本机识别结果为准。

## 升级方式与已知限制

- 从 `v0.0.39` 打开 **设置 → 更新 → 版本和更新**，在更新就绪后选择 **安装并重启**。不必为了升级先手动清空旧配置。
- 本地用正式 `v0.0.39` 整包和实际 `v0.0.40` 候选包做过隔离演练：直接升级、旧进程无响应时退出、模拟启动失败后回滚并重试均通过。完整夹具和实机驱动验收未覆盖。
- 旧版安装器采用覆盖安装，可能留下不再使用的旧网页资源。演练中新版目标文件齐全，但不是全新安装。
