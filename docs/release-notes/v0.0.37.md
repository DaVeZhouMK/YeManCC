# YeManCC v0.0.37

本版整合当前主线的手柄、更新、模块维护及 Steam 接入改动。实际可用项目随输入来源、机型能力和支持软件显示。

## 更新内容

- 整合当前唯一主线的手柄校对、输入来源及退出归还处理。
- 包含后台预下载、游戏期间暂停下载、目标版本替代及下载就绪通知入口。
- 包含更新退出、占用重试、中断恢复、模块维护与配置迁移链路。
- 带入当前 Steam 外观及 Decky 接入改动；真实 Steam、游戏和各机型效果需独立验证。
- 保留 34 项认可 HC 精简 DLL、单份 HIDMaestro.Core，以及不含重复输入载荷 ZIP 的完整包布局。

## 安装与升级

完整运行包仍为 **YeManCC.zip**，解压后保持 `YeManCC/` 和 `PowerControl/` 同级。

0.0.35 用户继续使用原更新入口升级；0.0.36 本地测试用户使用相同完整包升级。更新前保存游戏进度并退出游戏；出现文件占用或旧程序未退出时，保留恢复数据后重试。驱动或 HIDM/BUS 等模块提示需要重启时，重启后的实际状态单独验收。

## 附件

- `YeManCC.zip`：完整运行包。

软件模拟和发布门通过不等同于所有机型、物理设备或重启后的实机验收。支持范围与已知限制以实际设备能力及各项回执为准。
