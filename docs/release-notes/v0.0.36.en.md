# YeManCC v0.0.36 · Make Steam the home of your handheld

**English release draft / In preparation** · [简体中文](v0.0.36.md)

> This is preparation copy for 0.0.36. The final build, validation, and published package will determine the release scope.

Bring SteamOS-style convenience to Windows. The 0.0.36 draft brings together startup, controls, Steam appearance, and game tools around the things handheld players do every day, making adjustments before and during play more connected.

## Areas being prepared

- **Boot into your own setup.** Global, Xbox full screen, Windows + Steam Big Picture, and Xbox full screen + Steam Big Picture modes organize performance, controls, monitoring, and linked apps into complete presets. Saved boot modes take effect after restart.
- **Make the buttons work your way.** Edit physical-controller inputs, combinations, and supported device buttons in one place. Choose triggers and actions, then save reusable controller presets.
- **Keep adjustments close to Steam.** The YMCC Decky sidebar brings together power, frame limits, fans, and input settings, alongside ongoing connection-repair and bundled-update maintenance.
- **Give your library its own look.** Control dynamic wallpapers and eight Steam appearance effects independently, with preset restoration, original-appearance restoration, and reapply options.
- **Find game tools more easily.** Access OptiScaler FSR / XeSS, Lossless Scaling, game speed controls, and trainers. The simple value editor narrows its search using an initial value and a changed value.
- **Clearer information and measured background activity.** Refine monitoring layouts and fields, update downloads, and cache management, using power conditions and on-demand work to manage background activity.
- **Keep improving Windows handheld details.** Continue integrating sleep-time pause, original-game resume, Steam wake associations, and fan, charging, and device-status feedback.

## Downloads and availability

Once published, the complete installation and automatic-update package remains **YeManCC.zip**. See the [project overview](../../README.en.md) for download and installation links.

Hardware features depend on device support; game tools depend on the target game and supporting software. The radial menu is a test feature. Steam wake recovery, exclusive-fullscreen monitoring, and actual in-game input require separate validation. Simulation figures are not measured FPS or battery-life results.
