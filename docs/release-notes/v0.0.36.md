# YeManCC v0.0.36 · 让 Steam 成为你的掌机主场

**中文发布稿 / 准备中** · [English](v0.0.36.en.md)

> 本页是 0.0.36 发布文案准备稿。功能范围以最终构建、验证与正式发布包为准。

把 SteamOS 的顺手，带进 Windows。0.0.36 围绕掌机玩家每天都会遇到的操作，集中整理启动、操控、Steam 外观与游戏工具，让进入游戏前和游玩中的调节更连贯。

## 本轮整理重点

- **开机就进入你的主场。** 全局、Xbox 全屏、Windows + Steam 大屏、Xbox 全屏 + Steam 大屏四种模式，把性能、操控、监控和联动软件组织成整套预设；保存后重启生效。
- **按键按你的习惯来。** 实体手柄、组合键与受支持的专用键统一编辑，设置触发方式和动作，并保存可复用的手柄预设。
- **Steam 内外，调节更集中。** YMCC Decky 侧栏承接功耗、锁帧、风扇与输入设置；继续整理连接修复和随整包更新的维护流程。
- **游戏库更有自己的样子。** 动态壁纸与八项 Steam 外观效果可分别控制，并提供预设恢复、原外观恢复和重新应用。
- **游戏增强更容易找到。** 汇集 OptiScaler FSR / XeSS、小黄鸭、变速和修改器；“简单改数值”用当前值与变化值逐步缩小搜索范围。
- **信息更清楚，后台更克制。** 完善监控外观与字段组织、更新下载和缓存管理；通过供电条件与按需工作控制后台负担。
- **继续完善 Windows 掌机细节。** 睡前暂停、原游戏恢复、Steam 唤醒关联，以及风扇、充电和设备状态反馈持续整合。

## 下载与适用范围

正式发布后，完整安装与自动更新继续使用 **YeManCC.zip**。下载和安装入口见 [项目首页](../../README.md)。

硬件相关功能按设备能力开放；游戏增强依赖对应游戏与工具。触摸轮盘为测试功能。Steam 唤醒恢复、独占全屏监控与实际游戏输入等场景需分别验证，模拟数据不作为提帧或续航实测。
