# YeManCC v0.0.36

## 更新内容

- 新增手柄校对页面，集中管理摇杆、扳机等校对设置；实际可用项目随输入来源和机型能力显示。
- 完善后台自动预下载：游戏运行时暂停，断线后恢复下载，未完成目标可被后续新版本接替；下载就绪通过监控通知提示。
- 加强更新时的程序退出、文件占用重试、中断恢复和失败回滚，兼容手动更新与自动更新。
- 统一模块维护与配置迁移入口，保持用户配置与受管默认模板的边界；需要重启的模块维护按实际状态提示。
- 补充输入生命周期、手柄接管及退出归还处理，并带入最新主线的小修正。
- 保持 HC 精简，完整包只携带一份 HIDMaestro.Core，不再携带重复输入载荷 ZIP。

## 安装与升级

- 完整运行包为 **YeManCC.zip**，解压后保持 `YeManCC/` 与 `PowerControl/` 同级。
- 0.0.35 用户使用原更新入口升级；更新前请保存游戏进度并退出游戏。
- 如果旧版程序无响应导致更新助手无法确认退出，先退出旧程序再重试。更新失败时保留恢复数据，不要混合复制不同版本文件。
- HIDM/BUS 等外部模块如提示需要重启，请完成重启后再次检查模块状态。
