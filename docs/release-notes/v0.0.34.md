# YeManCC v0.0.34

## 更新内容

- **YMCC 控制台侧栏**：将 Decky 侧栏入口、游戏快捷操作及主线状态联动纳入完整包；随包附带锁定的 Windows Loader 与插件资源。
- **风扇控制与恢复**：更新风扇能力门禁、恢复证据、会话状态及安装脚本修复路径，载荷仍按身份清单校验。
- **帧率与 Steam 设置**：更新独立帧率设置、性能计划界面、Steam 监控设置与 Lossless Scaling 配置入口。
- **屏幕触控板与界面**：更新独立触控板、光标、快捷应用、背景及窗口边缘布局；整合已合并的窗口定位与自适应修正。
- **发布构建**：沿用已修复的 MSVC/.NET CI 环境处理；完整发布包含整包、源码 ZIP、版本清单和 SHA-256 校验文件。

## 安装与升级

- 使用唯一整包 **`YeManCC.zip`**，同时用于完整安装与自动更新；不要改名为 `YeManCC-Complete.zip`。
- 保持 ZIP 目录结构：`YeManCC/` 与 `PowerControl/` 同级，自定义游戏库位于 `YeManCC/CustomSteamLibrary`，风扇运行载荷位于 `PowerControl/fan-host-v2`。
- 本版供群友测试。更新前建议备份用户配置；升级与回滚遵守随包更新清单。
- 源码附件 **`YeManCC-source-v0.0.34.zip`** 对应发布标签的源码，不含本机安装数据或临时测试产物。

## 测试边界

CI 与隔离测试不能替代所有机型的实机验收。请反馈机型、触发步骤和日志，尤其是风扇能力、睡眠/唤醒、真实游戏侧栏/OSD 与触控板行为；不声明这些功能在全部设备上均已验证。
