## YeManCC v0.0.43

- **Steam 和 Decky**：更新 Steam 主题应用与刷新、侧栏连接恢复及动态壁纸播放。动态壁纸在不可用的播放路径上可以回退。
- **手柄与设备**：改进手柄服务的退出和电源状态衔接；更新 Fan Host，补充 ONEXPLAYER F1 相关设备的风扇识别，同时保留已发布的 GPD 修复。
- **升级**：加固安装接续和失败追踪；快速导出可在构建前锁定目标版本及源码提交，包装完成后会读回可执行文件、实际前端入口和升级清单的版本。

`YeManCC.zip` 是完整程序包；`YeManCC-source-v0.0.43.zip` 是对应源码。可用 `SHA256SUMS.txt` 核对下载。
