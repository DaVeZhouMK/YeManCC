# YeManCC v0.0.38

本版重点完善手柄快捷动作与触控鼠标、Steam / Decky 恢复、性能调节，以及配置和升级可靠性。

## 手柄与触控鼠标

- **新增键盘组合与顺序动作**：支持 1–4 键组合，可追加按键、组合和等待步骤，支持复制、排序、指定次数执行及再次触发停止循环。取消、切换目标或退出时处理本次动作的松键与释放。
- **修复自定义呼出键被旧默认键干扰**：替换或删除默认快捷动作后，不再由隐藏的肩键组合继续触发旧动作。
- **新增独立“触控鼠标”页面**：集中显示鼠标与屏幕触控板设置，改进手柄状态图标、页面布局及返回导航。
- **完善鼠标自动模式**：普通前台应用默认放行，保留鼠标黑白名单优先级；按当前前台游戏身份暂停，避免后台游戏或游戏识别暂未完成时误关浏览器等应用。
- 改进手柄校对中的摇杆、扳机原始输入和修正预览；减少编辑菜单遮挡期间的重复绘制，并改善不同分辨率下的导航与缩放。

## 陀螺仪与机型适配

- 修复显式开启陀螺仪时预设触发与输出参数未完整带入的问题，避免需要重新切换预设才能接续。
- 完善 **ROG 系列“百式”恢复**的供数观察、取消和恢复判断；该恢复范围限定 ROG，其他机型继续使用各自原有通道。
- 改进壹号本系列传感器发现：常规枚举为空时补查陀螺仪与加速度计类型，完善机型轴向及输入来源匹配。
- 补齐壹号本 X1 系列输入接入、X2 端点身份核对，以及 **X2 Mini Pro** 的分区双色、常亮、呼吸、亮度和关灯操作路径。
- 修正 OneXPlayer Mini AMD 的风扇占空比范围，并按设备会话核对风扇控制归还。
- 修正 MSI / ROG 分区灯光的左右颜色控件，细化 OneXPlayer 3 的预设、功能键颜色及固定速度提示。“氛围”在这些路线中表示分区配色。

## 性能调节与模拟

- **更新 TS 性能模拟工作台**：复用实际性能面板，支持同瓦数 A/B 对比、临时调节、恢复和重置，确认保存后才应用正式设置。模拟曲线是估算结果，不代表硬件跑分或实际帧率。
- 完善手动 CPU 电压偏移的能力判断与反馈，区分 AMD 全核 Curve Optimizer 和 Intel core/cache 电压域；仅在用户点击应用时提交，不在打开页面时自动套用。
- 完善按 Windows L3 域选择的进程亲和性控制，分别显示请求、应用和回读状态；这项操作不表示物理 CCD 断电。
- 减少重复进程查询、虚拟输入诊断清理、页面测量与监控读取；未确认的状态保留为未知，避免用错误默认值驱动后续动作。

## Steam、Decky 与游戏工具

- 加强 Steam 外观在唤醒、界面文档变化和助手忙碌后的有限补查；手动编辑优先，旧电源状态的迟到结果不覆盖新状态。
- 完善 Decky 按阶段恢复和失效上下文清理，保留用户设置；区分连接健康与功能读取失败，减少重复恢复和迟到回执干扰。
- 改进自定义游戏库动态壁纸选择与弱网下载：新素材下载期间保留选择意图和已有预览，修正候选切换、预览回执及当前条目刷新。
- **小黄鸭顶部面板增加“解除此游戏”**，并统一一键开关状态。解除操作移除当前游戏的配置关联，保留游戏程序文件。
- 监控状态读取失败时保留用户已选模板与大小，提示重新应用；补充已启用网络加速任务在唤醒后的一次性补启动检查。

## 睡眠与唤醒

- 新增“睡眠超时”选项：电源键睡眠请求后 240 秒仍在运行时尝试重试，人工唤醒优先。未设置时默认开启，保留用户已保存的关闭选择。
- 电源按钮增加“关闭屏幕”选项；改进屏幕、睡眠和休眠超时设置的保存反馈，避免保存后读取失败又显示成旧值。
- 改进游戏暂停与恢复的进程身份核对及诊断信息，区分实际暂停操作与旧状态复用。

## 配置、更新与模块维护

- 加强应用、更新和相关工具配置的损坏检测、保存读回与恢复处理。修复前保留受支持的损坏配置原件；无法识别的新格式、占用或权限问题明确报告。
- 后台预下载继续遵守游戏期间暂停的规则；减少关闭、离线或无需工作时的检查，保留目标版本替代与断点恢复流程。
- 安装完成状态以受保护的安装事务为依据，避免仅凭进度或握手文件误报完成。
- USB/IP 维护分别核对已装程序与驱动，改进重启后的接续判断；需要重启时按提示处理，身份不明或仍被占用时不反复卸载、安装。
- 电池管理改由 YMCC 进程内承载，减少独立后台程序；升级后仅对已确认身份的旧电池程序进行清理，保留未知文件与用户配置。
- 继续采用已批准的 HC 精简交付布局、单份 `HIDMaestro.Core.dll`，不重新带回重复的 `ymcc-input-payload.zip`。

## 安装与升级

完整运行包仍为 **YeManCC.zip**。手动解压时保持 `YeManCC/` 与 `PowerControl/` 同级，不要只替换主程序。

0.0.37 用户继续使用原更新入口。更新前保存游戏进度并退出游戏；驱动或 HIDM / BUS 等模块提示重启时，按提示重启 Windows。请勿手动删除无法确认用途的配置和恢复记录。
