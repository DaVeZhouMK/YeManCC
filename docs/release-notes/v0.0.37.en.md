# YeManCC v0.0.37

Release notes. [简体中文](v0.0.37.md)

This version integrates the current mainline controller calibration and input lifecycle work, background update downloads and game pause policy, update recovery, module maintenance, configuration migration, and Steam appearance/Decky changes. Device and game behavior require separate validation.

The complete runtime package remains **YeManCC.zip**, with sibling `YeManCC/` and `PowerControl/` directories. The approved 34 compact HC DLLs and single HIDMaestro.Core layout remain required; the retired nested input payload ZIP must stay absent.

Users of 0.0.35 and local 0.0.36 builds use the existing updater and the same complete package. Save game progress and close games before updating.

Attachments are `YeManCC.zip`, `YeManCC-source-v0.0.37.zip`, `version.json`, and `SHA256SUMS.txt`. Software validation does not establish compatibility with every physical device, game, driver, or reboot scenario.
