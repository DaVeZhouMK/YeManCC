# YeManCC v0.0.39

本版重点修复旧升级数据阻断安装的问题，补齐旧模块清理，并改进手柄操作、降压设置、动态壁纸和机型功能。

## 升级与模块维护

- **修复旧升级记录阻断新版本安装的问题**：损坏、格式不兼容、过大或异常的旧升级记录与模块收据可重建；以通过校验的新包为安装基准，不再要求先完整保留旧记录才能继续升级。
- **补齐旧模块文件清理**：即使新版本文件已经齐全，也会检查并清理 YMCC 自有模块目录中的过期 DLL，重建相应收据；不再仅为清理旧状态要求重新取得完整安装 ZIP。
- 改进同名目录、异常文件链接和只读旧文件的处理。只在已确认的 YMCC 文件范围内隔离或替换，不跟随链接清理外部目录，也不清空其他 Decky 插件。
- 加强主程序替换和失败恢复：使用本次安装独立的暂存与恢复目录，校验当前主程序及本次恢复副本，避免陈旧备份覆盖主程序；修复尚未完成时保留本次新包来源。
- 进度显示记录写入失败不再单独触发安装回滚；真实安装状态仍以本次安装事务为准。安装、模块更新与收尾清理继续共用维护互斥，清理异常也能释放占用，便于条件恢复后重试。
- Decky 的可选旧收据无法读取时，不再阻断新代码和新收据更新；新插件身份与文件校验先于旧数据清理完成。

## 手柄、快捷动作与触控鼠标

- 修复快捷动作管理浮层打开后焦点留在原卡片、方向键跑到其他卡片，以及按 B 直接关闭整个编辑器的问题。取消管理操作后返回原卡片，保留当前编辑草稿。
- 改进动作列表与编辑栏之间的左右导航，减少屏幕键盘、手柄图示和焦点变化引起的重复布局计算，改善编辑页面操作流畅度。
- 改进摇杆校对与陀螺仪输出图示的显示过渡；显示平滑不改变校对值、数值读数或实际手柄输出。
- **FPS 陀螺仪预设改为默认按住 LT 触发**，LT 不再同时默认绑定变速触发。其他预设与已保存配置仍按各自规则使用。
- 明确鼠标模式的名单行为：“开启”挡允许游戏内使用，同时继续遵守名单和 YMCC 前台暂停；“自动”挡继续按当前前台游戏暂停。ROG 系列不支持的微软鼠标通道显示原因及 JoyXoff 提示。
- 屏幕触控板的闲置隐藏同时覆盖 YMCC 呼出键与专用按键；保持按住时不隐藏，触摸原区域后恢复显示。
- 加强虚拟手柄关闭、退出、输入源重新确认和 OneX 系列迟到设备通知的处理；恢复仍受当前设备身份与原操作期限约束，失败会保留诊断结果。

## 性能与电源

- 性能调度面板补齐 **CCD 调度入口**，与设置页共用按 L3 缓存域选择的进程调度设置；这项操作不表示物理关闭 CCD。
- 补充 **AMD Strix Halo 388/395** 的功耗表兼容与运行时校验，沿用既有 TDP 控制通道；具体设备仍需通过能力探测，不按商品型号名称直接放行写入。

- **降压设置增加“即时试用、延后保存”**：调整经通道接受后开始 30 秒试用，再保存为下次使用的设置；再次调整重新计时。切换页面或隐藏到后台不会重置试用。
- 性能调度快捷入口与设置页共用同一降压开关，支持取消本次调整和恢复默认。退出、关机、睡眠或相关进程故障会取消尚未完成的保存。
- 不支持或身份未确认的降压通道不发送请求；界面区分“请求已接受”“设置已保存”与硬件实际回读。试用计时完成不代表硬件稳定性已经验证。
- 改进多电池设备的真实电源来源与充放电状态共享；完善唤醒密码设置的保存、回读和错误反馈，仍遵守系统组策略限制。

## Steam 壁纸与游戏工具

- 完善桌面监控的显示条件、准星选项及默认摆放，减少与 YMCC 呼出区域重叠；保留用户已经拖动保存的位置。

- **动态壁纸增加“离电关闭”**：开启后，电池供电时暂停播放、缓存和下载，接通电源后按原开关恢复；真实电源状态尚未确认时暂停相关任务。
- 完善媒体下载暂停原因与磁盘余量、缓存容量等提示，处理电源切换期间的迟到结果，避免暂停后旧任务继续写入或提交。
- 改进小黄鸭一键插帧入口，显示程序运行状态，并集中提供关闭和删除当前游戏关联配置的操作；删除关联配置不会删除游戏文件。
- 改进 OptiScaler 选择与设置浮层在窗口缩放、滚动和不同分辨率下的位置，保留手柄焦点操作。
- 网络加速开机选项增加独立保存记录与失败反馈；没有已保存选择时初始化默认开机设置，保留用户明确保存的关闭选择。
- 修复 Decky 音质开关状态持续观察中的浏览器计时器调用问题。

## 机型功能

- 微星屏蔽模式增加事件触发的手柄用途恢复：打开 YMCC、唤醒和 LB＋RB 切换后按既有设备通道核对；组合键切换后保留 3 秒等待。实际按键效果仍需按机型验证。

- 完善 OneX 系列背键、专用键与物理按键预览，保留各型号点击、按住及输入来源的差异。
- 补充 APEX 灯光协议接入与设备会话核对；完善 OneXPlayer 3 充电读写过程的身份重核，以及 Super X 独立充电路径的接入与限制说明。
- 各机型功能继续按实际识别结果、固件与运行时通道显示；上述改动不代表 OneX 全家族的虚拟输出、震动、充电或灯光都已通过实机验收。

## 安装与升级

完整运行包为 **YeManCC.zip**。手动解压时保持 `YeManCC/` 与 `PowerControl/` 同级，完整更新配套文件。

升级前保存游戏进度并退出游戏。旧升级缓存、断点记录及模块收据必要时会自动重建；HIDM / BUS 等模块提示重启时，按提示重启 Windows。

若旧版在新升级助手接管前就报错，可下载本版完整包，退出 YMCC 及相关工具后手动解压更新。新包内的修复需要由新版本代码执行，不能保证旧版自身的所有前置错误都能自动跨过。
