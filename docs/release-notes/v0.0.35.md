# YeManCC v0.0.35

## 更新内容

- **全屏唤出布局**：保留远端已合并的 PR #11 修复，唤出全高状态按显示器身份和边界绑定；跨屏、拓扑变化或查询失败时清除旧锁存，避免窗口回流时高度退缩。

- **YMCC 控制台侧栏**：更新启动与自动接入、资源和生命周期处理、全局快捷操作、下拉选择及手柄输入；继续随包分发锁定的 Loader 与 SDK 资源。
- **独立屏幕触控板**：补充特殊按键、光标及独立输入行为，调整设置面板与快捷入口。
- **手柄与界面导航**：调整游戏专属配置、菜单视觉行序与顶部电源分组导航；整理帧率设置和 Steam 监控界面。
- **Steam 游戏状态与策略**：更新会话观察和脚本联动，完善 Lossless Scaling 配置支持条件及操作边界。
- **导出与安装包身份**：加强源码 → 构建 → 暂存 → ZIP 的字节身份链，核对侧栏六项必发资产，防止旧资源混入新整包；此审计元数据不作为应用运行时的额外拒绝门。
- **完整发布链**：沿用 MSVC/.NET 构建机环境修复、锁定 SDK 完整性、版本无关升级回归，以及子游戏库主线版本同步。

## 安装与升级

- 完整安装与自动更新使用唯一运行包 **`YeManCC.zip`**；保留 `YeManCC/` 与 `PowerControl/` 同级结构，不使用 `YeManCC-Complete.zip`。
- 自定义游戏库位于 `YeManCC/CustomSteamLibrary`；正式风扇载荷位于 `PowerControl/fan-host-v2`。
- 完整发布应附带 `YeManCC-source-v0.0.35.zip`、`version.json` 与 `SHA256SUMS.txt`。源码 ZIP 对应正式发布冻结树，不是安装包。
- 群友测试前建议备份配置。升级器按清单保留用户数据并执行校验/回滚；不声明本轮已做真实旧客户端 UI 或全面实机升级验收。

## 实验功能与测试边界

**Steam HUD 仍是显式启用的实验探针，正常发布构建禁用。** 当前没有正式的统一实时监控数据接入，也不能把 Steam 大屏/Overlay DOM 接入或示例数据测试当作全部游戏模式绘制与输入验收。

本版包含控制台启动、触控板、导航及导出链更新，但离线/隔离测试不代替各机型风扇能力、睡眠唤醒、真实游戏侧栏/OSD、独占全屏或全部外设组合的实机测试。请反馈机型、复现步骤与日志。
