# YeManCC v0.0.39

This release fixes obsolete update data blocking installation, completes legacy module cleanup, and improves controller controls, undervolting, animated wallpapers, and device features.

## Updates and module maintenance

- **Recover from obsolete update metadata**: damaged, incompatible, oversized, or abnormal old update records and module receipts can be rebuilt. A verified incoming package is the installation baseline; preserving every old record is no longer a prerequisite.
- **Clean up obsolete module files even when the new files already match**. Retire old DLLs within YMCC-owned module folders and rebuild receipts without requiring another complete ZIP solely for cleanup.
- Improve handling of read-only files, directory collisions, and abnormal file links. Replacement stays within verified YMCC paths and does not follow links into external folders or clear other Decky plugins.
- Use installation-specific staging and recovery files. Verify the current executable and this operation's recovery copy, reject stale backups, and retain the incoming source while repair remains incomplete.
- A progress-record write failure no longer causes installation rollback by itself. Authoritative transaction state still determines completion. Installation, module updates, and final cleanup share the maintenance lock, with release guaranteed when cleanup throws.
- Unreadable optional legacy Decky receipts no longer block new code and canonical receipts. Incoming plugin identity and file hashes are checked before legacy metadata is reset.

## Controller controls, shortcuts, and touch mouse

- Fix shortcut management popups retaining focus on the original card, navigating into unrelated cards, or closing the entire editor on B. Closing a management popup returns to its card and preserves the editing draft.
- Improve navigation between the action list and editor pane. Reduce repeated keyboard, controller preview, and focus layout calculations.
- Smooth calibration and gyro-output drawings without changing calibration values, numeric readings, or controller output.
- **The FPS gyro preset now uses hold-LT activation by default**, with no default simultaneous speed-change trigger on LT.
- Clarify mouse-mode rules: On allows use in games while respecting lists and pausing in YMCC; Auto continues to pause for the foreground game. Unsupported Microsoft mouse support on ROG devices explains the restriction and points to JoyXoff.
- Include the YMCC summon button in touchpad idle hiding. Held contacts remain visible, and touching the original area restores the controls.
- Strengthen virtual-controller shutdown, exit, source revalidation, and late OneX device-notification handling. Recovery remains bound to the current device identity and original operation deadline.

## Performance and power

- Add the **CCD scheduling control** to the performance panel, sharing the L3-cache-domain process-scheduling setting with Settings. This does not physically power off a CCD.
- Add **AMD Strix Halo 388/395** power-table compatibility and runtime validation using the existing TDP channel. Runtime capability checks remain mandatory; product model names do not authorize hardware writes.

- **Apply undervolting for a trial before saving**: an accepted adjustment starts a 30-second trial, then saves the setting for later use. Another adjustment restarts the trial; changing pages or hiding the app does not.
- Share one undervolt switch between performance controls and Settings, with cancellation and reset actions. Exit, shutdown, sleep, or a related process failure cancels pending saves.
- Unsupported or unconfirmed channels do not receive voltage requests. Distinguish request acceptance, saved settings, and actual hardware readback. Completing the trial does not establish hardware stability.
- Improve shared physical power-source and charging information on multi-battery devices. Improve wake-password persistence, readback, and error feedback while retaining system policy restrictions.

## Steam wallpapers and game tools

- Improve desktop HUD visibility and crosshair controls, and avoid the YMCC summon area when choosing a default position. Retain user-saved dragged positions.

- **Add “Turn off on battery” for animated wallpapers**: pause playback, caching, and downloads on battery power, then resume according to the existing switches on AC. Related work also pauses while the physical source is unknown.
- Improve download pause reasons, free-space and cache-capacity feedback, and rejection of stale results across power transitions.
- Improve the Lossless Scaling shortcut with process status and a focused menu for disabling or removing the current game's association. Removing the association does not delete the game.
- Improve OptiScaler popup placement during resizing, scrolling, and resolution changes, retaining controller focus support.
- Persist an explicit network-acceleration startup preference and report failures. Initialize the default only when no saved choice exists; retain an explicitly saved disabled choice.
- Fix browser timer invocation used by retained Decky sound-toggle status observation.

## Device features

- Add event-driven controller-purpose recovery under MSI shielding when opening YMCC, resuming, or switching with LB+RB. Retain a three-second wait after the combination and the existing device-channel checks; physical key behavior still needs device-specific validation.

- Improve OneX rear/special-key consumption and physical-key previews while retaining model-specific click, hold, and source behavior.
- Add APEX lighting-protocol integration with device-session checks. Strengthen OneXPlayer 3 charge-operation identity checks and integrate the separate Super X charging path with its stated limitations.
- Availability still depends on exact device identity, firmware, and runtime support. These changes do not establish hardware acceptance for every OneX virtual output, vibration, charging, or lighting feature.

## Installation and upgrading

The complete runtime package remains **YeManCC.zip**. Keep `YeManCC/` and `PowerControl/` side by side and update the matching files together.

Save game progress and exit games before installation. Old update caches, resume records, and module receipts may be rebuilt. Restart Windows when HIDM / BUS or another module requests it.

If an older client fails before the new update helper takes control, download this release's complete package, exit YMCC and related tools, and update manually. Fixes delivered in the new code cannot guarantee bypassing every pre-installation failure in an old client.
