# 0.0.36 开发合入：Decky 更新与安装检查

本次是开发主线改动，目标随 0.0.36 发布。已发布的 0.0.35 包不含本次改动；不要把线上同版本检查当作开发改动的更新验证。本地版本号由正式发布批次统一修改，本任务不上传远端。

- Decky 自身更新与 YMCC 整包备用的能力、平台限制和明确确认，见 `docs/decky-update-release-gate.md`。
- Windows 底座改用官方 v3.3.0 的 PluginLoader-win-noconsole.exe，保留原字节与官方 SHA256；不再重打包或维护 Loader 内部补丁。Windows 上游自身更新尚不完整，使用现有 YMCC 整包更新。升级入口为 tools/decky-loader-upgrade.ps1；GitHub 发布前强制在线核对官方最新稳定版及文件身份。
- `tools/build-workspace.ps1`、`tools/package-release.ps1`、`tools/deploy-installed.ps1` 与 GitHub 发布上传前均要求本轮有效的更新检测回执。
- 本地开发安装追加 `Write-ExportInstalledIdentityFromArchive`：先确认安装后的 Native/Web/Decky 与本轮构建匹配，再从已校验的完整包提取构建身份记录、备份并替换旧记录，避免文件更新后仍报告旧构建。
- 对应回归验证旧记录确实更新、旧记录备份、其他构建记录拒绝、Decky 文件不匹配拒绝；导出身份测试共 59 项。测试已经接入 Decky 更新 Build 必检。现有完整更新包安装/启动握手失败恢复/子程序失败恢复检测保留。
- 手动测试入口使用完整 `chcp.com` 路径，避免 PATH 缺少系统目录时出现“chcp 不是内部或外部命令”。

0.0.36 必须从当前主线重新构建并打包，重新取得 Build / Package / Verify；此前 0.0.35 本地测试包的记录不用于放行新增源码。

本次源码修改没有重新启动正在运行的 YMCC / Steam / 游戏。用户已运行本地修复 cmd，主程序与 Decky 插件的安装哈希已核对一致；最新的安装身份同步修正属于待 0.0.36 重建的源码改动。
