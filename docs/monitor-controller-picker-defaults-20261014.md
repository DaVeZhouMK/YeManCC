# 监控图片手柄选择与自动隐藏默认值 — 2026-10-14

用户要求：手柄可打开自定义图片选择；无数据自动隐藏默认开启。

## 实现

- 监控的“自定义图片”选项与“选择图片”按钮复用已安装原生 `dialog.openFile`。统一手柄引擎的 A 操作仍走原有确认入口，不修改全局手柄引擎。
- 浏览器样式预览保留 HTML file input；原生运行时直接打开 Windows 文件选择窗口，避免程序式点击依赖浏览器用户激活。
- 复用既有 `shell.run` 读取明确选择的文件，没有新原生入口或采集层。路径以 UTF-8 Base64 数据传入，命令以 UTF-16 编码参数传入；不执行用户文件名中的文本。
- 输入上限仍为 12 MiB。每次读取最多 4 MiB，编码后低于现有 native 8 MiB 进程输出限制；大文件至多三次只读操作。长度和修改时间跨段校验，变更或读取不完整时报错，不组合错误图片。
- 沿用既有 PNG/JPG/WebP 签名验证、透明边裁切、单色化及有界 WebP 输出。只在用户导入时处理，不增加监控定时器、后台线程或数据刷新频率。
- 原生选择期间阻止重复进入。取消或转换失败保留原图片；离开监控页后异步结果不应用到配置。
- `hideUnavailable` 未保存或不是布尔值时默认为 true，显式 false/true 原样记忆。不重写自定义数据或其他设置。本机原本已保存 true。
