# YeManCC v0.0.36 发布准备与升级验证

## 发布准备状态

本说明用于 0.0.36 发布候选。手柄校对任务完成后重新冻结最终源码、核对成品身份，再执行正式发布。当前不代表已经通过全部回归或实机验收。

## 更新内容

- 新增手柄校对页面，提供摇杆、扳机和对应来源的校对设置；最终支持范围以校对任务交付和设备能力回执为准。
- 完善后台预下载：复用原更新管理器，游戏运行时暂停，保留可恢复下载进度，处理未完成目标被后续版本替代的情况；下载就绪通过已有监控通知入口提示。
- 加强升级退出与失败恢复，处理进程退出超时、受占用文件和中断后的重试；退出无法确认时保留恢复数据。
- 整理配置基准，随包替换受管默认模板，按原迁移合同保留用户配置。
- 保持 HC 精简布局，HIDMaestro Core 在完整包中只保留一份，模块引导复用完整包和原维护锁。

## 从 0.0.35 升级

- 重点核验公开正式版 0.0.35 到 0.0.36 的原升级链；下载、哈希、目录与模块处理、用户配置、运行中退出和失败恢复分别留存结果。
- 完整安装与更新使用唯一运行包 YeManCC.zip，保持 YeManCC/ 与 PowerControl/ 同级。
- HIDM/BUS 等模块如需真实重启，按实际维护状态提示用户；不把文件复制成功作为驱动或重启后验收。
- 正式附件应包括 YeManCC.zip、YeManCC-source-v0.0.36.zip、version.json 与 SHA256SUMS.txt。

## 验证边界

后台升级的反向模拟、公开 035 消费者检查和最终候选包身份将分别记录。旧 035 测试包的结果不转记为最终 036 的执行结果；各机型、真实游戏、外部插帧工具、设备和重启后的行为仍按各自证据说明。
