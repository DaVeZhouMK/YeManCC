# 野蛮系统控制中心 YeManCC

野蛮系统控制中心（YeManCC）是一款面向 Windows 游戏设备和高性能电脑的综合控制工具，帮助用户集中管理性能、功耗、CPU、游戏、Steam 大屏和系统启动项。

## 主要功能

- 性能调度：自动或手动切换多档性能配置。
- TDP 功耗控制：调节功耗上限、FPS 目标和自动应用策略。
- CPU 调度：管理 CPU 性能档位、睿频、核心和电源方案。
- 游戏监控：查看游戏、FPS、功耗、温度和 CPU/GPU 状态。
- 游戏暂停与恢复：睡眠前暂停游戏，唤醒后自动恢复。
- Steam 大屏：启动 Steam 大屏模式，并管理相关启动项。
- 模拟鼠标：支持 JoyXoff 和微软鼠标方案。
- 开机启动：管理 YeManCC、RTSS、JoyXoff 等常用程序。
- 快捷应用：音乐播放、显示设置、游戏加速、FSR 4.1 等功能。
- 支持自定义游戏配置，为不同游戏保存独立的性能方案。

## 安装方法

1. 从主页下载“完整系统”压缩包。
2. 将压缩包解压到：

   `C:\SOFT\YeMan`

3. 解压完成后，目录结构应保持如下形式：

   ```text
   C:\SOFT\YeMan\
   ├─ YeManCC\
   │  ├─ YeManCC.exe
   │  └─ ...
   └─ PowerControl\
      ├─ pawnio\
      └─ ...


      双击运行：
C:\SOFT\YeMan\YeManCC\YeManCC.exe

首次运行后，根据需要在“设置”“性能调度”“TDP 功耗”和“开机启动”页面进行配置。

手动优化包
手动优化包用于按照个人需求进行额外的 Windows、游戏和系统优化。
建议先完成完整系统的安装和测试，再根据自己的硬件、游戏和使用习惯选择性应用手动优化内容。应用前请阅读对应说明，并保留必要的系统还原点或备份。
注意事项
TDP、CPU、电源方案和开机启动等功能可能需要管理员权限。
不同电脑的硬件能力不同，部分功能会根据硬件支持情况显示或隐藏。
请不要删除 PowerControl 目录中的运行组件。
用户配置会保存在 PowerControl 目录中，升级或重新安装时请注意保留配置文件。
使用前请确认电脑已经安装必要的显卡驱动、芯片组驱动和 Windows 更新。
本程序主要面向游戏和性能调节场景，修改系统参数前请确认自己了解相关设置的作用。
