# YeManCC · 野蛮系统控制台

**简体中文** | [English](README.en.md)

## 把 SteamOS 的顺手，带进 Windows。

**让 Steam 承载更多，让掌机专注游戏。**

YeManCC（YMCC）是野蛮系统的开源掌机控制台。围绕 Windows 上的 Steam 大屏，把全手柄操作、SteamDeck 式输入、性能调节和动态游戏库整合到一起。配合野蛮系统，让选游戏、调设置、回到游戏成为连贯的掌机体验。

[下载完整运行包](https://github.com/DaVeZhouMK/YeManCC/releases) · [安装与构建说明](docs/getting-started.zh-CN.md) · [反馈问题](https://github.com/DaVeZhouMK/YeManCC/issues)

## 01 · Steam 成为掌机主场

![YMCC 整体体验：ROG 掌机上的 Steam 大屏、游戏库与全手柄操作](docs/images/ymcc-steam-experience.jpg)

熟悉 SteamOS 的顺手，也想保留 Windows 的游戏生态？让 **Steam 大屏承担游戏入口，YMCC 补齐掌机控制**：用手柄浏览游戏库、启动游戏和调整常用设置，把注意力留在游戏里。

## 02 · YMCC × Decky，双界面随手调

![YMCC 双界面：独立控制台与 Steam 内的 Decky 插件侧栏](docs/images/ymcc-dual-interface.jpg)

**完整控制台与 Steam 内侧栏，两种方式管理同一台掌机。** YMCC 控制台集中管理性能、散热和操控；SteamOS 风格的 Decky 插件界面把功耗、锁帧、风扇与常用输入设置带进 Steam 大屏。按你的使用习惯选择界面，用手柄就能随手调节。

## 03 · SteamDeck 手柄＋屏幕双触摸板

![YMCC 操控：虚拟 SteamDeck 手柄、屏幕双触摸板与 Steam 输入设置](docs/images/ymcc-steamdeck-controls.jpg)

**没有实体触摸板，也能在屏幕上扩展双触摸板操作。** YMCC 提供虚拟 SteamDeck 手柄，把按键、陀螺仪和屏幕触摸板接入 Steam 输入；触摸区域与映射可按习惯配置。操控交给 Steam，自定义留给玩家。

## 04 · 游戏库动起来，全部游戏再次集结

![YMCC 动态游戏库：动态壁纸、自定义游戏导入及封面与背景编辑](docs/images/ymcc-dynamic-library.jpg)

**动态壁纸点亮 Steam 主页，本地游戏也能加入同一个游戏库。** 自动获取动态壁纸，整理游戏封面与背景，将非 Steam 游戏加入 Steam，统一浏览与启动。让 Steam 既是你的游戏入口，也是你的掌机个性主页。

## 围绕 Steam，能力不止 Steam

| 能力 | 带来的便利 |
| --- | --- |
| **性能与散热调节** | 自动或手动调度，分别设置插电与电池策略，为游戏保存专属方案，并管理支持机型的风扇。 |
| **自定义游戏监控** | 按需组合帧率、功耗、温度等信息，调整样式、位置与显示内容。 |
| **游戏增强工具** | 整合 OptiScaler FSR / XeSS、小黄鸭缩放插帧、游戏变速与修改器入口。 |
| **Windows 睡眠与恢复** | 围绕睡前暂停、醒后恢复原游戏优化流程，让掌机日常使用更连贯。 |
| **掌机快捷操作** | 集中管理启动模式、显示、专用按键与快捷应用，减少反复进入桌面设置。 |

配图由掌机与软件界面素材制作，用于展示功能。具体能力取决于版本、设备、游戏及所需组件；性能与续航以实际设备测试为准。
